# Agent Cockpit v0.4.167

## Shipped For Users

- GitHub Copilot CLI is now available from desktop and mobile PWA conversations. Add a **Copilot** CLI profile, reuse terminal authentication, and choose from your account's available models and reasoning effort. Settings includes guided device login and checks installation, credentials and model access separately.
- Copilot conversations support native question cards, explicit steering, grouped delegated tools and retained summaries, and native goal set/status/pause/resume controls. Resuming a goal requires a fresh AI-credit limit. Stop, reset, archive and delete wait for owned work to finish cleanup before replacement work starts.
- Copilot works with Memory, Workspace Context, Knowledge Base and opt-in Workspace Routines. Model-supported image attachments and delivered files/images retain their previews and downloads after reload.
- Copilot usage separates ordinary tokens, cache tokens, context size, premium requests and explicitly reported AI credits. Quota shows freshness and availability; unknown units stay unknown, and unavailable USD estimates stay unavailable.
- Security dependency updates harden request-body and upload handling, redirects and schema validation, and address build-server and pattern-processing advisories.
- Copilot's current limits are documented: profiles share terminal authentication; native plan approval and Goal Clear are unavailable; hosted SDK PDFs and native image generation remain gated. A hosted steering attempt during tool work returned no response and remains an open finding despite passing local regressions.

## Developer Details

- [#571](https://github.com/daronyondem/agent-cockpit/pull/571) adds Copilot to profile/settings/onboarding, CLI detection, authentication, Install Doctor, updates and data-migration checks. Canonical behavior and limits are in [backend services](../spec-backend-services.md), [backend capabilities](../reference/backend-capabilities.md#github-copilot), [mobile PWA](../spec-mobile-pwa.md) and the [SDK evaluation](../research/copilot-sdk-parity-evaluation.md).
- Interactive conversations use pinned `@github/copilot-sdk` 1.0.28 connected to a Cockpit-owned headless CLI process. POSIX descendant tracking and Windows kill-on-close Job Objects contain native work. Opaque command overrides and restricted processor one-shots retain JSONL compatibility; interrupted work is never automatically replayed. Existing native session IDs and recovery snapshots remain supported, while active-turn reattachment after server restart is unavailable.
- Focused Copilot modules own protocol projection, correlated question/steering input, delegated tool ownership, model catalogs, native goals, quota, usage reconciliation and media. Shared browser-safe contracts feed desktop and PWA clients. Queue pauses are held only during a steering transaction; acceptance requires a native delivery event, and late input is withdrawn rather than queued for automatic execution.
- Native metrics are sampled before and after each SDK turn, subtracting prior session totals and separating cache-inclusive input. AI credits, premium requests and context snapshots are distinct; partial or unknown native billing data does not become a fabricated balance or USD price.
- Copilot uses production Memory/KB MCP paths, managed Context markdown and Routine inputs/output/history. Native fixtures cover scheduled/reset Context triggers, digestion/gleaning/dreaming, actual source reads, persistence, cancellation and detached-worker cleanup.
- The SDK requires Node >=22.12.0. Startup, all platform installer eligibility checks, Install Doctor and self-update use the same engine floor, preserving macOS symlink activation, Windows private-runtime behavior and legacy major-only manifests. ADR-0094 through ADR-0098 describe the protocol/ownership decisions; ADR-0098 retains its Proposed status.
- Steering regressions warm an existing conversation with real tool work, resume it, apply a correction while another foreground command runs, and cold-resume without replay. They include 300 ms and 61-second completion delays and matching Node 25.9.0 checks. The CLI may background the current command on immediate steering and report completion separately.
- The [owner's hosted report](https://github.com/daronyondem/agent-cockpit/pull/571#issuecomment-6658673116) verifies one existing shared account on macOS, 20 enabled models, actual hosted replies, web/narrow-PWA core workflows, Memory-to-Context recall, KB keyword retrieval, a manual Routine and explicit `gpt-6.1-sol` image input. It does not confirm full OAuth challenge completion, hosted goal pause/reload/fresh-limit resume, physical-device PWA behavior, live PWA delegation, expired/denied credentials, independent accounts or financial billing accuracy. The hosted steering failure remains unclassified and is not established as PWA-only.
- Release preparation updates Express to 4.22.3, body-parser to 1.20.9, Multer to 2.5.0, qs to 6.16.1, follow-redirects to 1.16.2 and both Vite roots to 8.1.6. Security overrides select Zod 4.6.6 without changing the SDK pin, glob 14.0.2 for affected newer glob branches, and minimatch 11.0.1 for affected newer minimatch branches. Existing basic-ftp/js-yaml overrides remain. See [locked dependency security](../spec-deployment.md#locked-dependency-security).
- Root audit retains only the low-severity, unpatched [deepmerge advisory](https://github.com/advisories/GHSA-gcqx-w48m-w2h4) through trusted Jest configuration processing. It is not used by the running application. Mobile audit has no findings. No moderate, high or critical findings remain in either audited lockfile.
- Release packaging rebuilds both production clients after the full test suite and rechecks the web bundle budget, so test fixture assets cannot replace the build copied into release archives. A focused workflow guard checks the ordering.
- Patched Vite adds 41 bytes to the desktop entry and 21 bytes to Settings. Their individual ceilings move from 267/80 KiB to 267.1/80.1 KiB; total limits remain 907 KiB JavaScript and 230 KiB CSS. No application behavior changes to accommodate the compiler.
