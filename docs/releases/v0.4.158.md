# Agent Cockpit v0.4.158

## Shipped For Users

- Claude Code and Claude Code Interactive can now use Opus 5 with a 1M context window and Sonnet 5. Both models expose Low, Medium, High, xHigh, and Max effort, support Ultracode mode, and participate in usage-cost estimates for input, output, and prompt-cache tokens.
- Kiro profiles now show the current Kiro CLI 2.13.1 model catalog, including Claude Sonnet 5, Claude Fable 5, GPT-5.6 Sol, GPT-5.6 Terra, GPT-5.6 Luna, and the corrected Claude Sonnet 4 model ID.
- OpenRouter profiles and assistant messages now use the current official OpenRouter logo across desktop and mobile.

## Developer Details

- Added pinned Claude Code metadata for `claude-opus-5[1m]` and `claude-sonnet-5`, made Sonnet 5 the static default, preserved previous model choices, and extended standard/interactive invocation guards plus Bedrock base-model projection through the shared metadata path. See [#491](https://github.com/daronyondem/agent-cockpit/pull/491).
- Added Anthropic pricing-catalog entries for Opus 5 and the Sonnet 5 introductory period, including input, output, cache-read, and five-minute cache-write rates. Wildcard patterns cover the Claude Code `[1m]` selector and embedded Bedrock inference-profile IDs while persisted pricing snapshots preserve historical estimates. [#490](https://github.com/daronyondem/agent-cockpit/issues/490) tracks the required Sonnet 5 standard-rate refresh after August 31, 2026.
- Updated the pinned Kiro catalog for CLI 2.13.1, retained image capability only for confirmed Claude-family models, kept GPT-family additions text-only pending upstream confirmation, and surfaced the internal-use warning for Claude Fable 5. See [#488](https://github.com/daronyondem/agent-cockpit/pull/488).
- Replaced the shared OpenRouter SVG while preserving `currentColor` behavior for CLI profile icons and desktop/mobile assistant avatars. See [#483](https://github.com/daronyondem/agent-cockpit/pull/483).
- Release preparation upgraded `adm-zip` to the patched 0.6 line and refreshed root/mobile lockfiles for patched `brace-expansion`, `body-parser`, `DOMPurify`, `nanoid`, and `postcss` versions. Root and mobile dependency audits report zero vulnerabilities.
