# Agent Cockpit v0.4.161

## Shipped For Users

- Codex profiles can now use GPT-6 Astra. The Codex model picker shows Astra as the default fallback model before live CLI model discovery finishes, with image-capable metadata and Low, Medium, High, xHigh, Max, and Ultra effort choices.
- Usage estimates now include GPT-6 Astra standard and Codex Fast pricing. Long prompts over the published 272,000-token threshold use Astra's long-context pricing so Estimated Cost stays aligned with OpenAI's current model rates.
- Kiro profiles now show Claude Opus 5 in the model picker with Opus-family, high-cost-tier, and image-input metadata while keeping `auto` as the default Kiro model.
- Release dependency checks are clean across the desktop/server and mobile package roots.

## Developer Details

- Added `gpt-6-astra` to Codex fallback metadata as the single static default, retained `gpt-5.6-sol` as a non-default fallback, and covered the fallback model list in `test/codexBackend.test.ts`. See [#523](https://github.com/daronyondem/agent-cockpit/pull/523).
- Added OpenAI GPT-6 Astra standard and Codex Fast/`priority` pricing entries, extended usage-pricing contracts with optional paired long-context fields, selected short vs long-context rates in the OpenAI/Codex calculator, and preserved long-context override fields through the Usage settings load/save path. ADR-0091 records the catalog-driven long-context pricing shape. See [#523](https://github.com/daronyondem/agent-cockpit/pull/523).
- Added Kiro CLI 2.14.2 Claude Opus 5 metadata in the pinned Kiro catalog, with focused backend coverage and backend spec updates. See [#493](https://github.com/daronyondem/agent-cockpit/pull/493).
- Release preparation refreshed root and mobile lockfiles for patched `@simplewebauthn/server`, `brace-expansion`, `browserslist`, `DOMPurify`, `ip-address`, `js-yaml`, `nanoid`, and PM2 dependency versions. The root package adds a narrow npm `overrides.qs = "6.16.0"` pin so Express 4's `qs` dependency resolves to the patched version without an Express 5 migration.
